## Bugs identificados (esta sesión)

### 🔴 BUG #1 — Crypto sin Stop Loss
**Archivo**: `signals/alpaca_broker.py:196-211`
**Problema**: Las posiciones crypto se abren con MARKET + notional SIN bracket. Alpaca no permite brackets con notional.
**Causa de pérdida**: DOGE cayó a $0.0823 sin protección → -$10,353 unrealized.
**Fix**: Después del BUY, emitir 2 órdenes separadas (STOP SELL + LIMIT SELL) vinculadas como OCO.
**Status**: ❌ NO IMPLEMENTADO

### 🔴 BUG #2 — Acumulación por falta de cap acumulado
**Archivo**: `signals/alpaca_broker.py:122-141`
**Problema**: `MAX_POSITION_PCT = 0.05` aplica por trade, no por symbol. Bot hizo 18 BUYs DOGE en 18 horas.
**Causa de pérdida**: $66k acumulados en DOGE.
**Fix**: Añadir `MAX_ACCUMULATED_USD = 5000` per symbol check.
**Status**: ❌ NO IMPLEMENTADO

### 🔴 BUG #3 — `has_position()` permite acumulación
**Archivo**: `signals/alpaca_broker.py:107`
**Problema**: Check no bloquea crypto correctamente; el bot sigue añadiendo a posición existente.
**Fix**: `if get_position_value(symbol) > $500: skip`
**Status**: ❌ NO IMPLEMENTADO

### 🟡 BUG #4 — Ping-pong por señales opuestas 1d+1h
**Archivo**: `signals/pipeline.py:131` + `main.py:974`
**Problema**: `paper-trade` ejecutaba señales 1d y 1h del mismo ticker. El cluster AMZN del 1-Jun mostró 6 reversals en 6 min.
**Fix**: Añadido `--interval` flag. AHORA FUNCIONA (ver cambios implementados).
**Status**: ✅ IMPLEMENTADO

### 🟡 BUG #5 — Parser `get_trade_history` no calculaba P&L
**Archivo**: `signals/alpaca_broker.py:290-323` (viejo)
**Problema**: Asumía `parent.legs[]` que la API de Alpaca no devuelve.
**Fix**: Pairing heurístico MARKET ↔ LIMIT/STOP filled.
**Status**: ✅ IMPLEMENTADO
