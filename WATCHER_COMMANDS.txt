================================================================================
PASO 1: INICIA WATCH 1H (ANÁLISIS CADA HORA)
================================================================================

En TERMINAL 1, copia y pega:

source venv/bin/activate && nohup python3 main.py watch \
  --tickers "SPY,QQQ,GLD,BTC-USD,ETH-USD,AAPL,NVDA" \
  --interval 1h \
  --every 3600 \
  --use-ml > watcher_1h.log 2>&1 &

✅ Inicia Watch 1H en background
📝 Logs guardados en: watcher_1h.log
⏱️ Ejecuta cada 3600 segundos (1 hora)
🤖 Usa modelo 1h + filtro ML

================================================================================
PASO 2: CONFIGURA WATCH 1D (PLAN DIARIO - UNA SOLA VEZ)
================================================================================

En TERMINAL 2, ejecuta:

crontab -e

Se abrirá un editor. Copia/pega ESTA LÍNEA EXACTA al final del archivo:

0 14 * * 1-5 bash -c 'source /home/alaindolea/proyectos/cfd-trading-system/venv/bin/activate && cd /home/alaindolea/proyectos/cfd-trading-system && python3 main.py watch --tickers "SPY,QQQ,GLD,BTC-USD,ETH-USD,AAPL,NVDA" --interval 1d --every 86400 --use-ml >> watcher_1d.log 2>&1'

Guarda el archivo:
  - Si usas NANO: Ctrl+X → Y → Enter
  - Si usas VI: :wq → Enter

✅ Watch 1D se ejecutará automáticamente a las 14:00 UTC (lunes-viernes)
📝 Logs guardados en: watcher_1d.log
⏱️ Ejecuta una sola vez al día
🤖 Usa modelo 1d para plan estratégico diario

================================================================================
TROUBLESHOOTING
================================================================================

¿Watch 1H no inicia?
  - Verificar venv: source venv/bin/activate && python3 -c "import tensorflow"
  - Verificar modelos: ls models/saved/multi_ticker_1d/
  - Ejecutar sin nohup para ver errores

¿Cron no ejecuta Watch 1D?
  - Verificar hora UTC: date -u (debe ser 14:00 UTC)
  - Ver cron jobs: crontab -l
  - Ver historial: grep CRON /var/log/syslog (opcional)

¿No recibe notificaciones Telegram?
  - Verificar .env: cat .env | grep BOT_TOKEN
  - Debe tener valores no vacíos
  - Probar: python3 -c "from signals.telegram_bot import TelegramNotifier; TelegramNotifier().send_alert('Test')"
